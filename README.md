# claude-dev-plugins

Coleção pessoal de plugins/skills para [Claude Code](https://claude.com/claude-code).

## Instalação

```
/plugin marketplace add ronaldoflima/claude-dev-plugins
/plugin install mac-to-linux-keys
```

## Skills

- **mac-to-linux-keys** — migra atalhos de teclado do Ubuntu/Linux para macOS usando Karabiner-Elements, hidutil e ferramentas complementares.
