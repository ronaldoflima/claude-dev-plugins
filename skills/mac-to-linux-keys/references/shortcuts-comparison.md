## Atalhos Emacs Nativos do macOS

Estes atalhos funcionam em TODOS os campos de texto no macOS. O remapeamento pode interferir:

| Ação | Atalho Emacs | Conflito Potencial |
|------|--------------|-------------------|
| Início da linha | Ctrl+A | Select All |
| Fim da linha | Ctrl+E | - |
| Deletar até fim da linha | Ctrl+K | - |
| Caractere anterior | Ctrl+B | - |
| Próximo caractere | Ctrl+F | Find |
| Linha acima | Ctrl+P | Print |
| Linha abaixo | Ctrl+N | New |
| Deletar caractere | Ctrl+D | - |
| Transpor caracteres | Ctrl+T | New Tab |

**Recomendação**: O remapeamento prioriza atalhos Linux sobre Emacs. Se você usa atalhos Emacs, considere ajustar o `linux-mode.json`.

---

## Notas

**(1) Ctrl+H → Cmd+H**: No macOS, Cmd+H é o atalho nativo para esconder (hide) a aplicação ativa. O remapeamento usa `Cmd+Option+F` como alternativa para "Find and Replace" em vez de mapear diretamente para Cmd+H, evitando que a aplicação seja escondida acidentalmente.
